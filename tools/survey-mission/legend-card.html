Rover indicator LED legend (8-pixel strip)

StripMeaning
Green: manual mode (leaving base, emergency intervention)
Red: autonomous mode, navigating
Sensing: first LED yellow (sensing mode), LEDs 2-8 show the detected ArUco tag ID in 7-bit binary, most significant bit first (white = 1, off = 0)

Example above: 0010001 = tag ID 17.
The same detected ID is written to the mission log on the SD card at the moment of detection, so every displayed value can be cross-checked.
